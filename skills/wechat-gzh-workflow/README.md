# wechat-gzh-workflow

一个人做公众号的写作流程技能，把「选题 → 写文 → 去AI味 → 配图 → 排版 → 整理进草稿箱」串成一套清晰步骤，来自作者本人真实在运营的公众号工作流。

## 它能帮你做什么

- 把做一篇文章拆成 6 个明确关卡，每关有固定输入输出，不用每次重新想流程。
- 约定工作区目录和文件命名，素材不散落，旧图可复用。
- 内置省钱原则和真实截图优先原则，避免无谓的出图开支和不可信的 AI 配图。
- 明确标出哪些环节必须人工把关，只提升写作整理效率，不代替你发布。

## 边界（重要）

- 技能的终点是把内容整理进微信公众号后台的**草稿箱**，不会替你群发。
- 是否发布、何时发布，由你本人登录后台手动确认。
- 不做批量号、无人值守群发或洗稿搬运。

## 安装

1. 把本目录复制到你 Hermess Agent Desktop 对应 Profile 的 skills 目录下。
2. 重启或在技能管理里刷新，确认出现 `wechat-gzh-workflow`。
3. 首次使用前，先按 SKILL.md 的「前置约定」建好你的工作区根目录。

## 依赖

- Hermess Agent Desktop v0.1.7+
- 至少一个可调用的文本模型
- 配图环节需要一个出图后端（也可以全程用真实截图，跳过 AI 出图）
- 整理进草稿箱环节需要按发布技能配置微信公众号凭据

## 说明

本技能只提供流程和约定，不包含任何平台账号或密钥。效果对照里引用的是作者自己的运营数据，仅供参考，不构成对你账号数据的承诺。
